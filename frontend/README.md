# Blog Frontend

Frontend for a full-stack blog application built using React, TypeScript, and Vite.

## Features

- User Authentication
- Responsive UI
- View All Posts
- Featured Post
- Post Details Page
- Create/Edit/Delete Posts
- Comment Section
- Like Posts
- Search Posts
- Pagination
- Role-Based Navigation

## Tech Stack

- React
- TypeScript
- Vite
- React Router
- Tailwind CSS
- Axios

## Folder Structure

```
src/
│
├── components/
├── pages/
├── hooks/

├── assets/
└── main.tsx
```

## Installation

Clone the repository

```bash
git clone <repository-url>
```

Install dependencies

```bash
npm install
```

Start development server

```bash
npm run dev
```

Application runs on

```
http://localhost:5173
```
